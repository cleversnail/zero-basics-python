## 0. 一次性准备：装 Django

```bash
# 建议先在项目里建一个虚拟环境（可选但推荐）
python3 -m venv venv
source venv/bin/activate            # Windows 用 venv\Scripts\activate

# 安装 Django（课程用的是 4.1.x）
pip3 install django==4.1.2
```

## 1.（第 99 讲）用 http.server 起一个静态服务器 —— 来自 97.txt

```bash
# 在任意想「发布」的目录里执行，默认端口 8000
python3 -m http.server

# 指定端口（例如 8080）
python3 -m http.server 8080

# 指定端口且对局域网开放（0.0.0.0 表示所有网卡）
python3 -m http.server 8080 --bind 0.0.0.0
```

> 对应课后作业：把 `/tmp` 目录发布到 8080 端口 →
> `cd /tmp && python3 -m http.server 8080`。

## 2.（第 101 讲）搭一个最小 Django 站点 —— 来自 98.txt

```bash
# 创建项目（会在当前目录下新建一个 mysite98 文件夹）
django-admin startproject mysite98
cd mysite98

# 创建应用（app）
python3 manage.py startapp myapp98

# 启动开发服务器：0.0.0.0:8000 表示监听所有网卡、8000 端口
python3 manage.py runserver 0.0.0.0:8000
# 浏览器访问 http://127.0.0.1:8000/  （或 http://<本机局域网IP>:8000/ ）
# 按 Ctrl+C 停止
```

## 3.（第 101–103 讲）Blog 完整流程 —— 来自 100.txt

### 3.1 创建 Django 环境

```bash
django-admin startproject mysite
cd mysite
python3 manage.py startapp myblog
```

### 3.2 修改 settings.py（连接 MySQL 数据库）

先在 MySQL 里建库（`mysql>` 是 MySQL 客户端提示符）：

```sql
mysql> create database django;
```

再把 `mysite/settings.py` 的 `DATABASES` 改成 MySQL（课程用 root / rootroot）：

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'django',
        'HOST': '127.0.0.1',
        'PORT': 3306,
        'USER': 'root',
        'PASSWORD': 'rootroot',
    }
}
```

> 💡 不想装 MySQL 的话，**保持默认的 SQLite 即可**——`startproject` 生成的
> `'ENGINE': 'django.db.backends.sqlite3'` 那份配置开箱即用，什么都不用改。

### 3.3 初始化数据库 / 建立 admin 后台用户

```bash
# 建默认的表（admin、auth 等内置 app 的表）
python3 manage.py migrate

# 创建超级管理员（会交互式让你输入用户名、邮箱、密码）
python3 manage.py createsuperuser

# 启动服务，后台地址 http://127.0.0.1:8080/admin/
python3 manage.py runserver 127.0.0.1:8080
```

> 管理后台地址：`http://127.0.0.1:8080/admin/`（课件的写法是 `http://127.0.0.1/admin`）。

### 3.4 创建模型并同步到数据库

```bash
# 每改一次 models.py，都要跑这两条：
python3 manage.py makemigrations   # 生成迁移文件（对应 myblog/migrations/000x_*.py）
python3 manage.py migrate          # 把迁移真正写进数据库
```

参考文档：<https://docs.djangoproject.com/zh-hans/4.1/intro/tutorial02/>

### 3.5 启动 Blog 服务（第 103 讲）

```bash
python3 manage.py runserver 127.0.0.1:8080
# 前台页面：http://127.0.0.1:8080/myblog/
# 管理后台：http://127.0.0.1:8080/admin/
```

## 附：常用 manage.py 子命令一览

| 命令 | 作用 |
| --- | --- |
| `django-admin startproject <名字>` | 创建一个 Django 项目 |
| `python3 manage.py startapp <名字>` | 在项目里创建一个应用 |
| `python3 manage.py runserver [IP:端口]` | 启动开发服务器（开发模式下改代码会自动重载） |
| `python3 manage.py migrate` | 把迁移文件同步到数据库（建表 / 改表） |
| `python3 manage.py makemigrations` | 根据 `models.py` 的变化生成迁移文件 |
| `python3 manage.py createsuperuser` | 创建后台超级管理员账号 |
| `python3 manage.py shell` | 打开带 Django 环境的交互式 Python |
| `python3 manage.py check` | 检查项目配置有无明显错误 |
