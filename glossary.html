语言与环境 ​

中文English说明
解释型语言interpreted language源码由解释器逐句翻译并执行，不需要单独的编译步骤。Python 属于这一类
编译型语言compiled language先把源码整体编译成机器码，再执行。如 C/C++、Go
字节码bytecode源码被编译成的中间形式，由 Python 虚拟机执行
解释器interpreter执行 Python 代码的程序；python3 -V 查的就是它的版本
交互模式interactive mode解释器跑完不退出，停在 >>> 等继续输入（python3 -i x.py）
非交互模式non-interactive mode从开始跑到结束，不中断（python3 x.py）
标准库standard libraryPython 自带的库，装了 Python 就能用，如 os、json、re
第三方库third-party library需要额外 pip install 的库，如 requests、pandas

基础语法 ​

中文English说明
变量variable给数据起的名字，随时可改指向
赋值assignmentx = 1，把右边给左边
数据类型data typeint / float / str / list / tuple / dict / set
整数integer (int)不带小数点的数
浮点数float带小数点的数
字符串string (str)用引号包起来的一串字符
列表list有序、可变、用 [] 表示，如 [1, 2, 3]
元组tuple有序、不可变、用 () 表示，如 (1, 2, 3)

切片slices[1:5:2] 取一段
类型转换type conversion / castingint("123")、str(456)
注释comment# 开头，给人看，不执行
关键字keyword语言保留字，不能当变量名，如 if、for、class
命名规范naming convention变量用小写下划线（snake_case）

易混淆概念对照 ​

容易混区别
列表 vs 元组列表可变（能改），元组不可变（不能改）；元组效率更高
列表 vs 集合列表有序可重复，集合无序不重复
= vs === 是赋值，== 是比较是否相等
is vs ==== 比值，is 比是不是同一个对象（同一块内存）
/ vs /// 除法得浮点，// 整除得整数
可变对象作默认参数def f(x=[]) 是陷阱：默认值只在定义时创建一次，会被反复共用
浅拷贝 vs 深拷贝浅拷贝只复制第一层，里层还是同一份；深拷贝递归复制
import a vs from a import b前者用 a.b 访问，后者直接 b
语法错误 vs 异常语法错误在运行前就被拦下；异常在运行时才发生
进程 vs 线程进程有独立内存，通信要 IPC；线程共享内存，但受 GIL 限制
while vs forwhile 条件成立就循环，for 遍历可迭代对象
append vs extendappend([4,5]) 把整个列表当一个元素加进去；extend([4,5]) 逐个加
