第 105 讲 · 理论盘点：人脸识别的一般步骤 ​

本节目标 ​

理解「计算机为什么能识别人脸」，并记住人脸识别的四个一般步骤。

知识要点 ​

1. 人脸识别的原理

计算机里的视频，本质上也是一张张图片；而图片是由数字组成的。既然是数字，就可以用数学计算去做图像识别。

人脸识别任务是图像识别的一个子类。图像识别可以拆成两个任务：

任务干什么本质
图像检测找出图像里有没有人脸、人脸在哪一种分类问题（有 / 没有）
图像对比把检测出的人脸，和预先采集的人脸比相似程度相似度计算

2. 人脸识别的一般步骤

  1. 把图片转换为灰度（去掉颜色、只留明暗，特征更好提）
  2. 识别图像中的人脸（把脸的坐标框出来）
  3. 训练特征库：将特定的人脸标注好，存入特征库
  4. 比对目标图片（视频）：对目标里出现的人脸做判断，根据相似程度做后续处理

3. 用 OpenCV 看图像的基本组成

  • 图像中的每一个像素点由三个元素组成，分别表示 R、G、B 三种颜色；
  • 一张图片的宽和高，由很多个像素点组成；
  • 像素点可以用数字表示，所以我们能用数学计算去处理图像。

💡 一句话：「看见」这件事，在计算机里就是「算数字」。

第 107 讲 · 怎样通过 OpenCV 采集视频信号？ ​

本节目标 ​

学会用 OpenCV 采集图片与视频信号：转灰度、开摄像头截图、读 MP4 文件。

知识要点 ​

1. 采集图片并转为灰度

  • 转换为灰度的目的是更好地提取特征（颜色是干扰，明暗才是人脸结构的核心）；
  • cv.cvtColor(图片, 转换方式) 用于颜色空间转换，比如 cv.COLOR_BGR2GRAY（BGR 转灰度）。

2. 采集视频信号并保存图片

要想识别特定的人脸，需要训练 OpenCV 的模型；训练数据一般就是从摄像头采集的截图（也可以是事先准备好的图片）。

用途函数
打开摄像头cv.VideoCapture(0)
从摄像头截图并保存cv.imencode(".jpg", 帧)[1].tofile(路径)

3. 采集 MP4 视频

cv.VideoCapture() 除了捕获摄像头，还可以读取 MP4 格式的文件（把参数换成文件路径即可）。 通过反复读取视频，可以不断优化 OpenCV 的模型。

代码实操 ​

下面是课程仓库里的采集脚本 face_demo/face_cap.py（完整代码）：

python
import cv2 as cv
# opencv
# pip3.9 install opencv-python
# pillow图像处理
# pip3.9 install pillow
# contrib 用于训练人脸模型的opencv扩展包
# pip3.9 install opencv-contrib-python
cap = cv.VideoCapture()
num = 1
face_name = "Boss"
face_id = 1

while (cap.isOpened()):
    #捕获摄像头图像
    ret_flag,vshow = cap.read()
    #显示捕获的照片
    cv.imshow("capture_test",vshow)
    #图像刷新的频率
    k = cv.waitKey(1)&0xff
    # 设置按键保存照片
    if k == ord('s'):
        # 保存图片
        cv.imencode(".jpg",vshow)[1].tofile(f"./imgdata/{str(face_id)}_{face_name}_{str(num)}.jpg")
        print(f"成功保存第{str(num)}张照片")
        num += 1
    elif k == ord(' '):
        break
# 关闭摄像
cap.release()
# 销毁窗口
cv.destroyAllWindows()

读一读这段代码里的几个关键点：

  • cv.VideoCapture() 不带参数 = 打开默认摄像头；cap.isOpened() 为真才进入循环。
  • cap.read() 返回两个值：ret_flag（这一帧读成功没有）和 vshow（图像数据）。
  • cv.waitKey(1) & 0xff 返回按键编码：按 s 存一张截图，按空格退出。
  • cv.imencode(".jpg", vshow)[1].tofile(路径) 把这一帧编码成 jpg 并存盘—— 文件名形如 1_Boss_1.jpg（标签号_名字_序号），这正是后面第 108 讲训练时要用的命名格式。

第 108 讲 · 如何训练人脸模型？ ​

本节目标 ​

理解训练人脸模型的三个关键动作：读取训练图片 → 加载分类模型 → 提取人脸特征。

知识要点 ​

1. 读取目录下全部训练文件

训练图片一般放在一个文件夹里，需要遍历目录，把所有文件路径以字符串形式存进一个列表：

用途函数
显示目录下所有文件os.listdir()
连接「目录 + 文件名」os.path.join()

python
import cv2 as cv
from PIL import Image
import numpy as np
from pathlib import Path

def getImageAndLabel(path):
    facesSamples = []
    ids = []
    
    #调用人脸分类器（注意自己文件保存的路径，英文名）
    face_detect = cv.CascadeClassifier('/Library/Frameworks/Python.framework/Versions/3.11/lib/python3.11/site-packages/cv2/data/haarcascade_frontalface_default.xml')
    #循环读取照片人脸数据
    for imagePath in Path(path).rglob("*"):
        #用灰度的方式打开照片
        PIL_img = Image.open(imagePath).convert('L')
        #将照片转换为计算机能识别的数组OpenCV（BGR--0-255）
        img_numpy = np.array(PIL_img,'uint8')
        #提取图像中人脸的特征值
        faces = face_detect.detectMultiScale(img_numpy)
        #将文件名按“.”进行分割
        id = int(imagePath.stem.split("_")[0])
        # 防止无人脸图像
        for x,y,w,h in faces:
            ids.append(id)
            facesSamples.append(img_numpy[y:y+h,x:x+w])
    return facesSamples,ids


faces, ids = getImageAndLabel('imgdata')

#调用LBPH算法对人脸数据进行处理
recognizer = cv.face.LBPHFaceRecognizer_create()

#训练数据
recognizer.train(faces, np.array(ids))

recognizer.write('trainer/trainer.yml')

第 109 讲 · 怎样设计人脸识别系统？ ​

本节目标 ​

把「分类器 + 训练好的模型」组装起来，做出一个能实时判断「是谁」的人脸识别系统。

知识要点 ​

1. 调用分类器和训练模型对图片进行人脸识别

用途函数
读取训练模型recogizer.read(训练模型文件)
人脸识别recogizer.predict(人脸像素块)

predict() 返回两个值：

  • ids：预测出的标签号（这个人是谁）；
  • confidence：可信度（越小说明越像、越有把握）。

2. 通过标注优化参数

默认模型往往识别效果不理想。用人眼通过矩形框标注，观察识别是否准确，再据此调整 detectMultiScale 的检测参数（如 scaleFactor、minNeighbors、人脸尺寸范围）和 判断阈值，逐步把系统调准。

代码实操 ​

课程仓库里的识别脚本 face_demo/face_detect.py（完整代码）：

python
import os
import cv2
from PIL import Image, ImageDraw, ImageFont
import numpy as np
from pathlib import Path

# 加载训练数据
recogizer=cv2.face.LBPHFaceRecognizer_create()
recogizer.read('trainer/trainer.yml')

names=["Boss"] # 名字
idn = [1] # 标签

# 识别图片
def face_detect_demo(img):

    gray=cv2.cvtColor(img,cv2.COLOR_BGR2GRAY)
    # 调用人脸分类器
    face_detector = cv2.CascadeClassifier('/Library/Frameworks/Python.framework/Versions/3.11/lib/python3.11/site-packages/cv2/data/haarcascade_frontalface_default.xml')
    
    # 读取人脸特征并返回人脸坐标
    face=face_detector.detectMultiScale(gray,1.1,5,0,(100,100),(800,800))
    for x,y,w,h in face:
        # 标记人脸
        cv2.rectangle(img,(x,y),(x+w,y+h),color=(0,0,255),thickness=2)
        # 识别人脸
        ids, confidence = recogizer.predict(gray[y:y + h, x:x + w])
        if confidence > 60:
            print("陌生人")
        else:
            print("老板来了，自动关闭游戏")
    cv2.imshow('result', img)


cap=cv2.VideoCapture(0)

while True:
    flag,frame=cap.read()
    if not flag:
        break
    face_detect_demo(frame)
    if ord(' ') == cv2.waitKey(10):
        break
cv2.destroyAllWindows()
cap.release()

三句话

  1. 计算机「看见」人脸的底层，是把图片当成数字做数学计算。
  2. 人脸识别 = 检测（找出脸在哪，分类问题）+ 对比（像不像，相似度）。
  3. 整条链路是：采集 → 灰度 → 检测 → 训练 → 预测，OpenCV 的 cv2.face 模块必须靠 opencv-contrib-python 才有。
