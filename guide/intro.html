一、这门课教什么 ​

整门课分成两大块：基础知识 + 项目实战。

基础知识（第 1–10 章）：

模块你会学到
学习编程的方法怎么查权威资料、怎么提问、怎么调试
常用数据类型数字、字符串、列表、元组、集合、字典
判断和循环if / match / while / for、语句嵌套

模块、标准库、第三方库导入、自定义模块、pip 装包
错误和异常异常的捕获与自定义

方向你会做出什么

二、编程能解决什么问题 ​

作者把「值得用程序解决的事」归成三类：

  • 重复性劳动——「脏活」「累活」。每天手动改 500 个 Excel，就该写脚本了。
  • 复杂的简单问题——比如「围棋」「斗地主」：规则简单，但人要算很久。
  • 把生活中的「事儿」归纳成规则，再交给计算机去交互执行。

落到具体收益上，有三个方面：

收益含义
自动化提升工作效率
定制化解决特定问题，而不是迁就现成软件
数字化自动分类、批量处理

三、Python 和其他编程语言的区别 ​

Python 的特点：

  • 是一种高级编程语言
  • 是解释型语言（写完直接跑，不需要先编译）
  • 语法和自然语言很像（if x > 0: 读起来就是英文）
  • 足够流行，应用行业广
  • 有丰富的库（标准库 + 第三方库）

Python 不适合的场景（这一条很重要，别被「Python 万能」带偏）：

不适合原因
抢购、电商等计算密集型场景纯 Python 计算慢；这类场景要 C/C++/Go
内存等底层硬件操作Python 屏蔽了硬件细节，反过来也就做不了精细控制
网页、小程序等前端开发那是 JavaScript / TypeScript 的地盘
App 开发主流是 Kotlin / Swift，不是 Python

💡 一句话：Python 是"胶水"和"效率工具"——它擅长把各种轮子粘起来快速解决问题，不擅长榨干硬件性能。

四、该怎么学 ​

课程把学习路径分成两种，对号入座：

如果 Python 是你的第一门语言：

  • 编程是门手艺，「我」不是美剧——两倍速看一遍学不会编程，得多敲代码。
  • 关注「用更少的代码解决问题」。
  • 代码不会永远正确，出问题时记得调试和跟踪。

如果 Python 是你的第二门语言：

  • 编程不能一蹴而就，要做好随时重构的准备。
  • 关注解释型语言和编译型语言的差异，尤其是内存分配方面的异同。
  • 学会提问——这是本课程反复强调的能力。

📖 课程指定的必读材料：《提问的智慧》（How To Ask Questions The Smart Way）。 中文版就在本仓库 [00-intro/How-To-Ask-Questions-The-Smart-Way.md(/guide/how-to-ask-questions)。
