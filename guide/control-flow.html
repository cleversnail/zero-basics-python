第 32 讲 · if 语句：数据流程出现分支时，怎样编写程序？ ​

本节目标 ​

学会用 if 让程序「根据条件走不同路」，并能写出一段判断奇偶、判断能否整除的小程序。

知识要点 ​

1. 什么是条件判断

程序默认是从上到下顺序执行的。但很多时候我们希望它「看情况办事」——比如机械臂要判断物体是否进入抓取范围、是否抓牢。这类「是否」的问题，在 Python 里用**条件判断（条件测试）**实现，对应语句就是 if。

判断的结果只有两种：真（True）和 假（False）——这就是布尔类型。注意 True / False 的首字母必须大写。

2. if 语句的语法

python
if 条件:
    条件为真时执行的语句
1
2

三个要点（少一个都会报错）：

  • 条件后面必须有冒号 :
  • 语句块必须缩进（一般 4 个空格）——缩进是语法，不是排版
  • 与 if 对齐（没有缩进）的语句，不属于 if 的语句块，无论条件真假都会执行

3. 三种写法

写法用途
if ...只有一个分支：条件为真才做
if ... else ...两个分支：为真做一件事，为假做另一件事
if ... elif ... else ...三个及以上分支：elif 是「否则如果」，可以写多个

4. 测试条件怎么写

写法含义
"date" == "2022-06-01"是否相等（注意是双等号 ==）
"date" != "2022-06-01"是否不相等
> < >= <=数值比较：大于、小于、大于等于、小于等于

⚠️ 常见混淆：= 是赋值（把右边给左边），== 才是判断相等。别写错。

代码实操 ​

完整代码见 code/32-if.py：

python
# 第 32 讲：if 语句 —— 数据流程出现分支时，怎样编写程序？
# 直接运行：python3 32-if.py

# 1) 最简单的 if：条件为 True 才执行缩进的那一条（或那几条）语句
if True:
    print("条件为真,执行该条语句")

if False:
    print("条件为假,不执行该条语句")
print("没有缩进,不是 if 语句块中的语句,执行")

# 2) if ... else：条件为真做一件事，为假做另一件事
if True:
    print("条件为真")
else:
    print("条件为假")

# 3) if ... elif ... else：处理三种及以上情况
number = 10
if number % 2 == 1:
    print("number是奇数")
elif number % 2 == 0:
    print("number是偶数")
else:
    print(f"number 的值是 {number}")

# 4) 测试条件：相等、不相等，以及数值比较符号
print("date" == "2022-06-01")     # 是否相等
print("date" != "2022-06-01")     # 是否不相等
print(3 > 2, 3 >= 3, 2 < 1, 2 <= 2)

# 5) 课后作业：随机生成 1~100 的整数，判断能否被 3 整除
#    为了让每次运行结果一致，这里固定随机种子；去掉 seed 就是真正随机
import random

random.seed(2026)
for _ in range(5):
    number = int(random.random() * 100 + 1)
    if number % 3 == 0:
        print(f"{number} 能被 3 整除")
    else:
        print(f"{number} 不能被 3 整除")

第 33 讲 · match 语句：如何通过 match 关键字来处理程序的分支逻辑？ ​

本节目标 ​

认识 match 语句——一种比 if...elif 更「对口」的分支写法，尤其适合判断「等于某个具体值」。

知识要点 ​

1. match 语句的语法

当你有一堆「等于某值就做某事」的分支时，match 比一长串 if...elif 读起来更清楚：

python
match 变量:
    case 值1:
        语句
    case 值2:
        语句
    case _:
        兜底语句

python
match http_response_status:
    case 400:
        print("Bad request")
    case 404:
        print("Not found")
    case 418:
        print("I'm a teapot")
    case _:
        print("Something's wrong with the internet")

  • match 语句需要 Python 3.10 及以上版本（本机 3.12.7 没问题）
  • 变量名 _ 是通配符，意思是「其他所有情况都归我」，它保证 match 一定能匹配到一条分支（相当于 if...elif 里的 else）

2. 模式组合

如果想把多个值放进同一个 case，用竖线 | 把它们连起来：

python
match http_response_status:
    case 400 | 403 | 404:
        print("4xx error")
    case 500 | 501 | 503:
        print("5xx error")

⚠️ PPT 里的一处笔误：PPT 写的是 case 500 or 501 or 503。但在真实的 Python 里，case 模式只认竖线 |，写成 or 会直接报 SyntaxError。写代码时请以 | 为准。

3. match 与 if 的分工

  • match 更擅长字面值比较（等于 400、等于 404 这种）
  • if 更擅长数值比较（大于、小于、区间判断）
  • 用 | 把多个值组合成一个模式，可以有效减少嵌套，让代码更短

完整代码见 code/33-match.py：

python
# 第 33 讲：match 语句 —— 如何通过 match 关键字来处理程序的分支逻辑？
# match 语句需要 Python 3.10 及以上版本
# 直接运行：python3 33-match.py

# 1) 基本用法：变量名 _ 是通配符，保证 match 一定能匹配成功
http_response_status = 500

match http_response_status:
    case 400:
        print("Bad request")
    case 404:
        print("Not found")
    case 418:
        print("I'm a teapot")
    case _:
        print("Something's wrong with the internet")

# 2) 模式组合：用 "|" 在一个模式里组合多个字面值
#    注意：PPT 里写法是 "case 500 or 501 or 503"，但在真实 Python 里
#    case 模式只认 "|"，写成 "or" 会直接 SyntaxError（见避坑说明）
http_response_status = 404

match http_response_status:
    case 400 | 403 | 404:
        print("4xx error")
    case 500 | 501 | 503:
        print("5xx error")
    case _:
        print("其他状态码")

    case 9 | 10 | 11:

    case 12 | 1 | 2:

第 34 讲 · while 循环：需要多次重复执行某段程序时，怎么做？ ​

本节目标 ​

学会用 while 循环重复执行代码，并掌握 break / continue 以及「用循环操作列表」的常见套路。

知识要点 ​

1. 循环是什么

循环是让一段代码多次执行的结构。它能把「啰嗦」的重复代码变短，让程序逻辑更强。程序设计的三大常用结构就是：顺序、判断（分支）、循环。

2. while 循环的语法

python
while 循环条件:
    循环体（要重复执行的语句）
1
2

只要「循环条件」为真，就一遍遍执行循环体；直到条件变假，循环才结束。

3. 循环的几种退出情况

情况说明
条件不满足循环自然结束
条件一开始就不成立循环体一次都不执行
break立刻跳出整个循环
continue跳过本次剩余语句，直接进入下一次循环
死循环条件永远为真，循环停不下来（要避免！）

⚠️ 最容易犯的错——死循环：如果循环体里忘了让条件「靠近终点」（比如忘记 number += 1），while 会永远跑下去。写循环时先想清楚：这条件最后靠什么变成假？

4. 用 while 操作列表

  • 把循环结果放进列表：先 list1 = []，再在循环里 list1.append(...)
  • 遍历列表：while list1: 表示「只要列表非空就一直循环」，配合 list1.pop() 不断取出元素，列表空了循环自然结束

代码实操 ​

完整代码见 code/34-while.py：

python
# 第 34 讲：while 循环 —— 需要多次重复执行某段程序时，怎么做？
# 直接运行：python3 34-while.py

# 1) 正向计数：1、2、3
number = 1
while number <= 3:
    print(f"number is {number}")
    number += 1
print(number)   # 循环结束时 number 已经是 4

# 2) 反向计数：3、2、1
number = 3
while number >= 1:
    print(f"number is {number}")
    number -= 1

# 3) 用 break 提前跳出循环
number = 10
while number >= 1:
    print(f"number is {number}")
    number -= 1
    if number == 5:
        break

# 4) 用 continue 跳过本次剩余语句
number = 10
while number >= 1:
    number -= 1
    if number == 5:
        continue
    print(f"number is {number}")

# 5) 用 while 把循环结果放入列表
list1 = []
number = 1
while number < 5:
    list1.append(number)
    number += 1
print(list1)

# 6) 用 while 遍历列表：不断弹出末尾元素，直到列表为空
list1 = [1, 2, 3, 4, 5]
while list1:
    print(list1.pop())

# 7) 课后作业：猜数字，最多猜三次
#    交互输入无法在文档里演示，这里用固定猜测序列代替 input()
target = 42                # 相当于随机产生的正确答案
guesses = [30, 42, 88]     # 相当于用户依次输入的三个数字
index = 0
while index < 3:
    guess = guesses[index]
    index += 1
    if guess == target:
        print(f"第 {index} 次猜中，答案是 {target}，游戏结束")
        break
    print(f"第 {index} 次猜 {guess}，没猜中")
else:
    print(f"三次都没猜中，正确答案是 {target}")

第 35 讲 · for 循环：如何遍历一个对象里的所有元素？ ​

本节目标 ​

会用 for 遍历列表、元组、字典，会用 enumerate() 给遍历加序号，会写简单的推导式。

知识要点 ​

1. for 与 while 的区别

  • while：条件驱动——只要条件为真就一直重复
  • for：遍历驱动——把某个对象（列表、元组、字典……）里的元素挨个儿过一遍

for 的语法：

python
for 变量 in 对象:
    循环体
1
2

「把对象里的元素一个个取出来处理」这个动作，术语叫迭代。

range(1, 5) 生成 1、2、3、4——含头不含尾，这是新手最容易记错的点。

2. 遍历字典的三种姿势

写法遍历的是
for title in movie1.keys():所有键
for value in movie1.values():所有值
for title, value in movie1.items():所有键值对

3. enumerate()：给遍历加上编号

enumerate() 会把「元素」变成「(编号, 元素)」的形式，配合元组解包就能同时拿到序号和内容：

python
for num, value in enumerate(movie1.items()):
    print(f"第 {num} 个字典元素是 {value}")
1
2

4. 推导式

推导式的作用是「从一个序列构造另一个序列」，格式为：

表达式 for 变量 in 序列
表达式 for 变量 in 序列 if 条件
1
2

它支持列表、字典、元组、集合。例如 [i * i for i in (1, 2, 3, 4) if i > 2] 会得到 [9, 16]。

代码实操 ​

完整代码见 code/35-for.py：

python
# 第 35 讲：for 循环 —— 如何遍历一个对象里的所有元素？
# 直接运行：python3 35-for.py

# 1) for 遍历元组：把每个元素挨个儿操作一遍
for temp_element in (1, 2, 3, 4):
    print(temp_element)

第 36 讲 · 语句嵌套：如何处理多重循环的问题？ ​

本节目标 ​

学会把判断、循环一层层套起来，处理更复杂的逻辑，并能打印出九九乘法表。

知识要点 ​

1. 什么是语句嵌套

语句嵌套就是「在一个语句里再写另一个语句」，是程序应对复杂逻辑的有效方法。条件语句、循环语句之间可以组成多层嵌套。

⚠️ 嵌套别超过 3 层：超过 3 层的嵌套既影响执行效率，也让读代码的人头疼。遇到多层嵌套，应该回到需求层面把任务拆分。

2. 在条件语句里套条件语句

以「找出 100 以内能被 7 整除的数」为例，两个条件（小于 100、能被 7 整除）有两种写法：

写法思路
写法一先判断「小于 100」，再用临时变量存中间结果，接着判断「能否被 7 整除」
写法二用 and 把两个条件合并进同一个 if

3. 在循环里套条件语句

最常见的场景是「遍历序列并做条件判断」。这种「循环 + 条件」还能改写成推导式：

python
>>> [x * x for x in range(10) if x % 7 == 0]
[0, 49]
1
2

4. 多重循环

多重循环常用来处理二维数据，比如一个 3×5 的矩阵：

[[1, 2, 1, 2, 0],
 [2, 2, 2, 1, 0],
 [1, 1, 2, 2, 0]]
1
2
3

外层循环一行行取，内层循环取行里的每个元素，就能把二维结构「拉平」成一维。

代码实操 ​

完整代码见 code/36-nested.py：

python
# 第 36 讲：语句嵌套 —— 如何处理多重循环的问题？
# 直接运行：python3 36-nested.py

# 1) 在条件语句里再写条件语句：找出 100 以内能被 7 整除的数
#    写法一：分步判断，用临时变量存储中间结果
number = 49
if number < 100:
    temp = number % 7
    if temp == 0:
        print(f"写法一：{number} 能被 7 整除")

#    写法二：把两个条件合并到一个 if 里
for number in (7, 49, 100):
    if number < 100 and number % 7 == 0:
        print(f"写法二：{number} 能被 7 整除")

# 2) 循环里嵌套条件语句，也能写成推导式
print([x * x for x in range(10) if x % 7 == 0])

# 3) 多重循环：把 3x5 的矩阵拉平成一维列表
data = [[1, 2, 1, 2, 0],
        [2, 2, 2, 1, 0],
        [1, 1, 2, 2, 0]]
list2 = []
for i in data:          # 外层循环：一行一行取
    for j in i:         # 内层循环：取行里的每个元素
        list2.append(j)
print(list2)

# 4) 课后作业：用嵌套循环在命令行打印九九乘法表
for i in range(1, 10):
    row = []
    for j in range(1, i + 1):
        row.append(f"{j}*{i}={i * j}")
    print(" ".join(row))

代码实操 ​

完整代码见 code/37-plane-war.py：

python
# 第 37 讲：小试牛刀 —— 飞机大战（有限回合、自动对打版）
# 原始代码用 pynput 监听键盘（需要装库、还要一直按键才能玩），
# 这里改成「有限回合、自动对打」的演示版：跑完自动退出，不会卡住。
# 直接运行：python3 37-plane-war.py

import random

random.seed(7)   # 固定随机种子，让每次运行结果一致

# 生成地图：3x3 网格，0 表示空位，"x" 表示我方飞机
background = [[0, 0, 0],
              [0, "x", 0],
              [0, 0, 0]]


def show_map():
    """打印当前地图。"""
    for row in background:
        print(row)
    print("-" * 12)


def find_player():
    """找到我方飞机当前坐标 (行, 列)，找不到返回 None。"""
    for i in range(3):
        for j in range(3):
            if background[i][j] == "x":
                return i, j
    return None


def move_player(direction):
    """按方向移动我方飞机，越过边界就不动。"""
    pos = find_player()
    if pos is None:
        return
    i, j = pos
    di, dj = direction
    ni, nj = i + di, j + dj
    if 0 <= ni < 3 and 0 <= nj < 3:
        background[i][j] = 0
        background[ni][nj] = "x"


# 敌机：每个敌机有名字和生命值
enemies = [
    {"name": "敌机A", "hp": 60},
    {"name": "敌机B", "hp": 40},
    {"name": "敌机C", "hp": 80},
]

player_hp = 100
moves = [(0, 1), (0, -1), (1, 0), (-1, 0)]   # 右、左、下、上

print("=== 飞机大战（自动对打版）===")
show_map()

round_no = 0
max_rounds = 6
while player_hp > 0 and enemies and round_no < max_rounds:
    round_no += 1
    print(f"\n第 {round_no} 回合")

    # 我方随机移动并显示地图
    move_player(random.choice(moves))
    show_map()

    # 我方开火，攻击当前目标敌机
    enemy = enemies[0]
    damage = random.randint(10, 30)
    enemy["hp"] -= damage
    print(f"我方开火，{enemy['name']} 受到 {damage} 点伤害，剩余生命值 {max(enemy['hp'], 0)}")
    if enemy["hp"] <= 0:
        print(f"{enemy['name']} 被击落！")
        enemies.pop(0)

    # 敌机反击
    if enemies:
        counter = random.randint(5, 20)
        player_hp -= counter
        print(f"敌机反击，我方受到 {counter} 点伤害，剩余生命值 {max(player_hp, 0)}")

print("\n=== 战斗结束 ===")
if player_hp <= 0:
    print("我方飞机被击落，游戏结束")
elif not enemies:
    print("敌机全部被击落，我方胜利！")
else:
    print(f"到达回合上限({max_rounds})，战斗中止。我方剩余生命值 {max(player_hp, 0)}")


# 课后作业演示：用 +、- 符号恢复 / 扣除血量，血量为 0 时游戏结束
# 交互按键无法在文档里演示，这里用固定按键序列代替键盘输入
print("\n=== 课后作业：血量增减演示 ===")
hp = 100
keys = ["+", "-", "+", "-", "-", "-"]   # 相当于用户依次按下的键
for key in keys:
    if key == "+":
        delta = random.randint(1, 100)
        hp = min(100, hp + delta)   # 最大血量 100
        print(f"按下 +，恢复 {delta} 点，当前血量 {hp}")
    else:
        delta = random.randint(1, 100)
        hp -= delta
        print(f"按下 -，扣除 {delta} 点，当前血量 {max(hp, 0)}")
    if hp <= 0:
        print("血量为 0，游戏结束")
        break

第 38 讲 · 避坑指南：判断和循环中的常见错误 ​

认识判断与循环里最容易踩的三个坑，看到「错误长什么样」，以后遇到能一眼认出。

⚠️ 本讲三个示例中，38-pitfalls-pop.py 是故意触发错误的，它会以 IndexError 退出——这是正常的演示，不是代码坏了。

知识要点 ​

避坑一：循环过程中改变遍历次数，改不动

python
for i in (1, 2, 3, 4, 5):
    i = 5
    print(i)
# 执行结果：5 5 5 5 5
1
2
3
4

在循环里给 i 赋值 5，并不会让循环提前结束——循环依旧执行 5 次。原因是：每次迭代开始时，for 都会用序列里的下一个值重新给 i 赋值，你上一次的赋值被覆盖了。想提前结束循环，应该用 break，而不是给循环变量赋值。

避坑二：遍历过程中修改列表，会导致误操作

python
list1 = ["a", "b", "c", "d"]
for i in range(len(list1)):
    list1.pop(i)
1
2
3

range(len(list1)) 在循环开始前就按原始长度 4 把索引定死成了 0, 1, 2, 3。可列表 pop() 之后长度会变短，索引越走越靠后，最终越界报 IndexError。

结论：列表、字典等可变对象，一旦长度被修改，就要重新遍历，别用固定长度的 for 去边遍历边改。

避坑三：嵌套循环的缩进不同，执行结果不同

缩进决定了「这句话属于哪一层循环」：

缩进位置执行时机
与内层循环体对齐内层、外层循环都会执行
与内层 while 对齐每次外层循环执行一次
与外层 while 对齐只在循环全部结束后执行一次

因为 Python 靠缩进划分语句块，一旦套了多层循环，缩进错一点结果就全不同。所以不建议构建 3 层以上的循环，该拆分就拆分。

第 39 讲 · 再回首：“判断循环”单元小结 ​

本节目标 ​

回顾本章学到的判断与循环工具，把「什么时候用哪个」心里理清。

知识要点 ​

本章把「让程序做选择」和「让程序重复干活」两件事讲完了，核心就三组工具：

判断（做选择）

  • if / if...else / if...elif...else：按条件走不同分支
  • 条件结果是布尔值 True / False；== 判相等、!= 判不等、> < >= <= 比大小
  • match ... case ...（Python 3.10+）：一堆「等于某具体值」的分支，用 | 组合多个模式

循环（重复干活）

  • while 条件:：条件为真就一直重复，适合「次数不确定」的场景
  • for 变量 in 对象:：把列表/元组/字典里的元素挨个过一遍，适合「遍历」
  • break 跳出整个循环；continue 跳过本次；while...else 在「没被 break」时执行

组合与避坑

  • 语句嵌套能把简单结构拼成复杂逻辑，但别超过 3 层
  • 循环里改循环变量，改变不了循环次数（要用 break）
  • 边遍历边修改列表/字典，会导致越界或遗漏（要重新遍历）
  • 缩进决定语句属于哪一层，嵌套里尤其要盯紧

代码实操 ​

三句话

  1. 判断让程序会选，循环让程序会重复——几乎所有程序的骨架都是「顺序 + 判断 + 循环」。

  3. 缩进就是语法：分支和嵌套里错一个缩进，结果可能完全不同；多层嵌套要克制。
