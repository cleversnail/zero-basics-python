第 66 讲 · 模块的导入：如何使用其他人编写好的代码功能？ ​

本节目标 ​

搞懂「模块」是什么，并学会 5 种把别人的代码「借」到自己程序里来的导入写法。

知识要点 ​

1. 什么是模块

模块就是一个以 .py 结尾的文件，里面存放着函数（也可以放变量、类）。 它的作用是：把函数放进模块文件里，隐藏代码细节，让主程序的逻辑更清晰—— 你只要会「调用」，不必知道它内部怎么实现。

2. 导入模块的 5 种写法

写法例子调用函数时的格式
导入整个模块import osos.getcwd()
导入指定函数from os import getcwdgetcwd()
一次导入多个from os import chdir, getcwdgetcwd()
起别名import datetime as dtdt.date(...)
导入包里的模块from datetime import datedate.today()

3. 包（package）

把多个模块文件放进一个文件夹，这个文件夹就叫包。包的导入和模块一样： import 包 或 from 包 import 模块；调用包里的函数时写成 包.模块.函数。

4. 两个提醒

  • ⚠️ 不建议用 from os import * 把模块所有函数都导进来——容易和现有名字撞车，也看不出函数来自哪里。
  • 💡 记忆口诀：import 后面接整块，from ... import 后面接零碎；用了 as 就用别名去调。

代码实操 ​

完整代码见 code/66-import.py：

python
# -*- coding: utf-8 -*-
"""第 66 讲 · 模块的导入：如何使用其他人编写好的代码功能？"""
import os

# 1. 导入整个模块：调用时写「模块名.函数()」
print("== 1. import os ==")
print(os.getcwd())

# 2. 只导入模块中的某个函数：调用时直接写「函数()」
print("== 2. from os import getcwd ==")
from os import getcwd
print(getcwd())

# 3. 一次导入多个函数
print("== 3. from os import chdir, getcwd ==")
from os import chdir, getcwd as cwd
print(cwd())

# 4. 给模块起别名：import 模块 as 别名
print("== 4. import datetime as dt ==")
import datetime as dt
print(dt.date(2026, 10, 10))

# 5. 从包中导入模块：包.模块.函数
print("== 5. from datetime import date ==")
from datetime import date
print(date(2026, 10, 10).year)

认识 Python 自带的标准库，学会「遇到新需求 → 查官方文档 → 找到合适模块」的方法。

知识要点 ​

1. 什么是标准库

标准库是随 Python 一起安装、不用额外安装就能直接 import 的模块集合。 它覆盖了文本处理、数字、文件与目录、网络与进程、并发执行等大量场景， 能显著提高开发效率。常见的组件有：内置函数 / 类型 / 异常、文本处理、数字、文件目录、 通用操作系统、并发执行、网络通信、互联网协议等。

第 68 讲 · 自定义模块：如何编写一个完整功能？ ​

本节目标 ​

学会把一组变量、函数、类写进一个 .py 文件，并让别的程序 import 它来用。

知识要点 ​

1. 创建自定义模块

  • 用以 .py 结尾的文件名保存模块；
  • 文件里定义的变量、函数都能被调用；
  • 文件里定义的类可以在引用模块时进行实例化（模块.类()）。

2. 自定义模块注意事项

  1. 导入自定义模块时，要确保导入路径正确（模块文件要在能被找到的目录里）；
  2. 文件名避免特殊字符，也避免和标准库重名（比如别叫 os.py）；
  3. 自定义模块多次导入，模块里的代码也只执行一次（Python 会缓存已导入的模块）；
  4. 模块里应只定义函数，把「调用 / 测试代码」放进 if __name__ == "__main__": 代码块里， 这样别人 import 你的模块时才不会误触发这些代码。

3. __name__ 是什么

每个模块都有内置变量 __name__：

  • 直接运行这个文件时，__name__ 等于 "__main__"；
  • 被别的文件 import 时，__name__ 等于模块名（这里是 "mymodule"）。

所以 if __name__ == "__main__": 里的代码只在直接运行时执行，被导入时不执行。

代码实操 ​

本讲需要两个文件，都放在 code/ 里。

（1）被导入的模块 code/mymodule.py：

python
# -*- coding: utf-8 -*-
"""mymodule —— 一个自定义模块，被 68-custom-module.py 导入。"""

var1 = 100                    # 模块里的变量


def func1():                  # 模块里的函数
    print("func1 is called")


class Class1(object):         # 模块里的类
    def __init__(self):
        print("Class1 is instance")


if __name__ == "__main__":
    print("mymodule 被直接运行（不是被导入）")
    func1()

请编写一个自定义模块，模块中定义 date() 和 time() 两个函数，分别用于显示当前的日期和系统时间。

python
# -*- coding: utf-8 -*-
"""自定义模块：提供 date() 和 time() 两个函数。"""
from datetime import datetime


def date():
    """返回当前日期，格式 2026-10-10"""
    return datetime.now().strftime("%Y-%m-%d")


def time():
    """返回当前时间，格式 13:48:00"""
    return datetime.now().strftime("%H:%M:%S")

第 70 讲 · 小试牛刀：如何使用 Python 为函数求导？ ​

本节目标 ​

综合运用「标准库 + 第三方库」完成一个数学任务：给函数求导，并画出函数图像。

知识要点 ​

1. 需求分析

用 Python 计算函数的导数，拆成几步：

  1. 找到能实现 Python 求导的第三方模块 → sympy；
  2. 安装并测试第三方模块；
  3. 用第三方模块计算函数的导数；
  4. 安装绘图模块并测试 → matplotlib；
  5. 绘制函数图像。

2. 两种求导思路

思路原理依赖
数值求导用中心差分公式 f'(x) ≈ (f(x+h) − f(x−h)) / 2h 近似纯标准库，零依赖
符号求导用 sympy 直接求出导函数表达式 2*x + 3第三方库 sympy

3. sympy 求导的两个关键 API

  • Symbol('x')：声明一个数学符号 x；
  • Derivative(y, x)：构造「y 对 x 求导」；再 .doit() 真正执行求导； 用 .subs({x: 10}) 把 x 代入具体数值。

代码实操 ​

完整代码见 code/70-derivative.py（本机已装 sympy 1.14.0、matplotlib 3.9.2）：

python
# -*- coding: utf-8 -*-
"""第 70 讲 · 小试牛刀：如何使用 Python 为函数求导？"""
# 待求导的函数：f(x) = x^2 + 3x + 2
def f(x):
    return x * x + 3 * x + 2


# 方法一：纯标准库做数值求导（中心差分近似）
def numeric_derivative(f, x, h=1e-6):
    return (f(x + h) - f(x - h)) / (2 * h)


print("== 方法一：数值求导（纯标准库）==")
print("f'(10) ≈", numeric_derivative(f, 10))

# 方法二：用第三方库 sympy 做符号求导
from sympy import Derivative, Symbol, limit, oo

x = Symbol("x")
y = x * x + 3 * x + 2
d = Derivative(y, x)

print("== 方法二：符号求导（sympy）==")
print("原函数 f(x)  =", y)
print("导函数 f'(x) =", d.doit())
print("f'(10)       =", d.doit().subs({x: 10}))

# 课后作业：(1 + 1/n)^n 当 n 趋近无穷大时的极限
n = Symbol("n")
print("== 课后作业：极限 ==")
print("lim (1+1/n)^n =", limit((1 + 1 / n) ** n, n, oo))
print("（数学上这个极限就是自然常数 e ≈ 2.71828）")

# 画图：把 f(x) 存成 png
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

xs = [i / 10 for i in range(-60, 31)]
plt.plot(xs, [f(v) for v in xs])
plt.title("f(x) = x^2 + 3x + 2")
plt.xlabel("x")
plt.ylabel("f(x)")
plt.savefig("derivative-plot.png")
print("== 图像 ==")
print("f(x) 的图像已保存到 derivative-plot.png")

第 71 讲 · 再回首："模块与标准库"单元小结 ​

本节目标 ​

把本章的「模块导入 / 标准库 / 自定义模块 / 第三方模块」串成一条线，形成整体印象。

知识要点 ​

1. 模块（module）

模块就是一个 .py 文件，里面可以放变量、函数、类；用它来隐藏细节、复用代码。

2. 导入方式的对应关系

导入写法调用格式
import 模块模块.函数()
from 模块 import 函数函数()
import 模块 as 别名别名.函数()
import 包.模块包.模块.函数()

3. 三类模块

  • 标准库：Python 自带，直接 import（如 math / json / zipfile）；
  • 自定义模块：自己写的 .py，注意别和标准库重名，用 __name__ 保护测试代码；
  • 第三方模块：pip install 装（如 requests / numpy / sympy），建议放虚拟环境里。

4. 完整功能靠多个模块配合

本章最后的求导例子，就是标准库（数值求导）+ 第三方库（sympy 符号求导、matplotlib 画图） 一起配合完成的——这正是模块化开发的常态。

代码实操 ​

完整代码见 code/71-summary.py：

python
# -*- coding: utf-8 -*-
"""第 71 讲 · 再回首：「模块与标准库」单元小结"""
import math
import importlib.metadata as md

# 1. 标准库：不用装，直接 import
print("标准库 math.pi =", round(math.pi, 5))

# 2. 第三方库：先 pip 安装，再 import
import sympy
print("第三方 sympy 版本 =", md.version("sympy"))

# 3. 模块名.成员 的调用方式小结
print("导入与调用方式：")
styles = [
    "import 模块          -> 模块.函数()",
    "from 模块 import 函数 -> 函数()",
    "import 模块 as 别名   -> 别名.函数()",
    "import 包.模块        -> 包.模块.函数()",
]
for i, s in enumerate(styles, 1):
    print(f"  {i}. {s}")

  1. 什么时候用 import 模块，什么时候用 from 模块 import 函数？

参考答案：① 想保留「函数来自哪个模块」的线索、或模块里很多东西都要用时用 import 模块； 只用一两个函数、嫌 模块. 前缀啰嗦时用 from 模块 import 函数。 ② 避免别人 import 你的模块时，把只该「直接运行才执行」的测试 / 调用代码也一起跑掉。 ③ 隔离依赖，避免和系统默认环境里的包版本冲突、互相污染。
