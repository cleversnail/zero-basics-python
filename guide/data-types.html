第 18 讲 · 内置数据类型包括哪几种？ ​

本节目标 ​

认识 Python 数据类型的「族谱」，并学会用 type() 查看任意一个值的真实类型。

知识要点 ​

Python 把数据按「怎么组织、能不能修改」分成几大类。内置类型就是语言自带、无需安装就能用的类型。

大类代表类型举例
数字类型int / float / complex10、3.14、1+2j
文本类型str"hello"
序列类型list / tuple / range[1,2,3]、(1,"a")、range(1,5)
集合类型set（可变）/ frozenset（不可变）{1,2,3}
映射类型dict{"one":1, "two":2}
布尔 / 空值bool / NoneTypeTrue / None

为什么要有这么多类型？ 用作者的话说，好处有三点：

  • 内置常用函数：每种类型都自带一批现成方法，拿来就用；
  • 运算符复用：同一套 +、in、[i] 在不同类型上有各自合理的含义；
  • 语义明确，不容易出错：看到 {} 就知道是集合或字典，看到 [] 就知道是有序列表。

处理数据的常见路径是：非结构化 → 半结构化 → 结构化。 一段文章是非结构化的，切成列表就变得有结构；用字典把「姓名→电话」关联起来，就是半结构化的键值对。

第 19 讲 · 列表：如何处理同类数据？ ​

本节目标 ​

认识列表的写法、创建方式、用索引取元素、以及删除元素和整个列表。

知识要点 ​

列表（list） 是存放一系列有序数据的容器：

  • 用方括号 [] 表示，元素之间用逗号 , 分隔；
  • 里面的元素可以是数字、字符串，甚至另一个列表；
  • 列表有序，每个元素都有编号（索引），下标从 0 开始；
  • 列表可以修改，定义之后还能增删改元素。

合法的列表写法举例：[1, 2, 3, 4, 5]、['aa', 'cc', 'dd']、[123, 'abc']、[[1,'a'], [2,'b']]。

创建列表有三种常见方式：

  1. 直接用 [] 写出来，如 colours = ["red", "blue", "green"]；
  2. 用内置函数 list() 转换，如 list("red") 会把字符串拆成 ['r','e','d']；
  3. 用列表推导式，如 [x for x in range(1, 10)]（循环章会细讲）。

索引访问：list1[0] 取第一个，list1[1] 取第二个，list1[-1] 取最后一个（负号表示从右往左数）。 嵌套列表要两级索引，比如 list2[2][0] 表示「第 3 个元素（它本身是个列表）的第 1 项」。

删除：del list1[0] 删掉某个元素；del list1 把整个列表删掉（之后再用它会报 NameError）。

代码实操 ​

完整代码 code/19-list.py：

python
# 第 19 讲 · 列表：如何处理同类数据？

# 创建列表：方括号 []，元素之间用逗号分隔
colours = ["red", "blue", "green"]
print(colours)
print(type(colours))

# 内置函数 list() 可以把字符串拆成「字符的列表」
print(list("red"))

# 列表推导式（第 35 讲细讲，这里先看一眼）
print([x for x in range(1, 10)])

# 索引访问：列表是有序的，下标从 0 开始，-1 表示最后一个
list1 = ["a", "b", "c", "d"]
print(list1[0])
print(list1[1])
print(list1[-1])

# 嵌套列表：元素本身也可以是列表
list2 = ["a", "b", ["c", "d"]]
print(list2[2][0])   # 第 3 个元素（一个列表）的第 1 项
print(list2[2][1])   # 想拿到字符串 'd'，就要这样两级索引

# 删除列表中的元素 / 删除整个列表
del list1[0]
print(list1)
del list1
print("list1 已被删除（再访问它会报 NameError）")

第 20 讲 · 常见常新：列表的常见操作 ​

本节目标 ​

掌握列表的增、删、查、排序等常用方法，并记住哪些是「原地修改」、哪些会返回新列表。

知识要点 ​

添加元素

方法作用
list.insert(索引, 元素)在指定索引位置插入元素
list.append(元素)在列表结尾追加一个元素
list.extend(可迭代对象)把可迭代对象逐个拆开追加

⚠️ append 和 extend 传列表时结果不同：append([1,2]) 会把整个列表当成一个元素塞进去；extend([1,2]) 会把 1、2 分别追加。

修改 / 删除元素

方法作用
list.remove(元素)移除第一个匹配的元素
list.reverse()反转顺序（原地）
list.pop(索引)移除并返回该元素；不写索引则移除最后一个
list.copy()复制列表（浅拷贝）
list.clear()清空列表

计算长度：len(list) 得到长度，len(list[0]) 得到第 1 个元素的长度，list.count(元素) 统计某元素出现次数。

排序：list.sort() 原地排序；sorted(list) 排序后返回新列表，原列表不变。二者都可加 reverse=True 表示降序。

代码实操 ​

完整代码 code/20-list-ops.py：

python
# 第 20 讲 · 常见常新：列表的常见操作

list_demo = ['a', 'b', 'c', 'd', 'e', ['f', 'g']]
print(list_demo)

# 添加元素：insert（指定位置插入）
list_demo.insert(0, "first")
print(list_demo)

list_demo.insert(-1, "last")   # -1 表示插在最后一个元素之前
print(list_demo)

# 添加元素：append（在结尾追加一个元素）
list_demo.append("last_one")
print(list_demo)

# 扩展元素：extend（把可迭代对象逐个拆开追加）
list_demo.extend("last_one")   # 注意：字符串被拆成了一串单个字符
print(list_demo)

# 移除元素：remove（移除第一个匹配项）
list_demo.remove("last_one")
print(list_demo)

# 弹出元素：pop（移除并返回指定索引的元素）
result = list_demo.pop(0)
print(f"list is {list_demo}")
print(f"result is {result}")

# 反转：reverse（原地）
nums = [3, 1, 2]
nums.reverse()
print(nums)

# 复制：copy（浅拷贝，改副本不影响原列表）
nums_copy = nums.copy()
nums_copy.append(99)
print("原列表:", nums)
print("副本:", nums_copy)

# 清空：clear（原地）
nums.clear()
print("clear 之后:", nums)

# 计算长度：len
print(len("abc"))          # 字符串的长度
print(len([1, 2, 3]))      # 列表的长度

# 统计出现次数：count
print([1, 2, 2, 3, 2].count(2))

# 排序：sorted() 返回新列表，原列表不变
data = [3, 1, 2]
sorted_data = sorted(data)
print("sorted 返回新列表:", sorted_data, "原列表不变:", data)

# 排序：list.sort() 原地排序
data.sort()
print("sort 原地排序:", data)

data.sort(reverse=True)
print("reverse=True 降序:", data)

第 21 讲 · 元组：如何处理一次性数据？ ​

本节目标 ​

认识元组，理解它与列表的区别，掌握序列的通用操作与元组的不可变性。

知识要点 ​

元组（tuple） 和列表很像，也是有序序列，但创建之后不可修改——所以适合存放「一次成型、以后不再变」的数据。

序列家族：基本序列包括列表、元组、range；字符串与二进制数据是特别定制的序列。

可变 vs 不可变：

  • 列表属于可变序列；
  • 元组、字符串属于不可变序列——append()、pop()、insert() 这些修改元素的函数，在它们身上用不了。

元组与列表的区别：

  1. 创建后：元组不可修改，列表可修改；
  2. 元组执行效率更高，列表相对低。

创建元组：用圆括号 () 定义；用 tuple() 函数创建；或把 range()、列表、字符串转换成元组。

序列的通用操作（列表、元组、range 都支持）：

运算结果
x in s若 s 中有某项等于 x，则为 True，否则 False
x not in s与上一行相反
s + ts 与 t 拼接
s * n / n * ss 与自身拼接 n 次
s[i]第 i 项，起始为 0
s[i:j]从 i 到 j 的切片
s[i:j:k]步长为 k 的切片
len(s)长度
min(s) / max(s)最小 / 最大项
s.index(x)x 首次出现的索引
s.count(x)x 出现的总次数

删除元组：用 del 可以删除整个元组。

代码实操 ​

完整代码 code/21-tuple.py：

python
# 第 21 讲 · 元组：如何处理一次性数据？

# 创建元组：圆括号 () —— 三种方式
color = ("r", "g", "b", "g", "b", "b")
print(type(color), color)

print(tuple("red"))        # 字符串 → 元组
print(tuple(range(1, 4)))  # range → 元组
print(tuple(["a", "b"]))   # 列表 → 元组

# 序列的通用操作（列表、元组、range 都支持）
s = (1, 2, 3, 4, 5)
print(1 in s)              # x in s
print(9 not in s)          # x not in s
print((1, 2) + (3, 4))     # s + t 拼接
print((0,) * 3)            # s * n 重复
print(s[0])                # s[i]
print(s[1:4])              # s[i:j] 切片
print(s[1:4:2])            # s[i:j:k] 带步长的切片
print(len(s))              # len(s)
print(min(s), max(s))      # min / max
print(s.index(3))          # 首次出现的索引
print(s.count(2))          # 出现次数

# 元组不可变：想「修改」只能拼一个新的
color2 = color + ("m",)
print(color2)

# 借助集合给元组去重
new_color = set(color)
print(new_color)
print(tuple(new_color))

知识要点 ​

集合（set） 的最大特点：元素唯一、不重复，而且无序。

  • 集合类型有两种：set（可变）和 frozenset（不可变）；日常编程中用 set 更多。

  1. 花括号内用逗号分隔元素，如 {'wilson', 'yin'}；

删除集合：用 del 删除整个集合对象。

第 23 讲 · 字典：如何处理映射类型的数据？ ​

本节目标 ​

认识映射与字典，掌握字典的三种创建方式、键的规则，以及删除操作。

知识要点 ​

映射（mapping） 描述的是「一对一的对应关系」，最典型的例子是「学号 → 姓名」「姓名 → 电话」。

  • 映射是可变类型；
  • Python 里映射只有一种数据类型，就是字典（dict）；
  • 字典里每个元素由键（key） 和值（value） 两部分组成，写作 {键: 值}；
  • 键不能重复，因此「不可哈希」的类型（如列表、字典本身）不能当键；
  • 整数 1 和浮点数 1.0 会被当作同一个键。

创建字典三种方式：

  1. 花括号：{'one': 1, 'two': 2}；
  2. 类型构造器：dict(one=1, two=2)；
  3. 字典推导式：{x: x**2 for x in range(10)}。

删除：del 字典 删掉整个字典；del 字典[键] 删掉字典里指定的那一个键值对。

  • 字典.setdefault(key[, default])：如果键存在就返回它的值；不存在就插入默认值并返回。

第 26 讲 · 小试牛刀：如何利用类型转换实现手机通讯录？（上） ​

本节目标 ​

理解「数据需要汇总、清洗、从非结构化转成结构化」这一思路，并动手把一段文章和一个 csv 通讯录转成结构化数据。

知识要点 ​

数据处理的思路：

  • 数据要汇总才能体现价值；
  • 大部分数据无法直接处理，需要先清洗掉噪声；
  • 数据要从非结构化（一段纯文本）转成半结构化（键值对）或结构化（列表、字典）形式。

本讲要解决的两件事：

  1. 文章分析：把一个文本文件读进来，统计总行数、非空行数、某个单词出现的次数；
  2. 通讯录转换：把以 , 分隔的 csv 每一行，读成一个字典 {'name': ..., 'source': ..., 'tel': ...}。

关键技巧：

  • 读文件用 f.readlines()，它返回一个列表，每一行（含换行符 \n）是一个元素；
  • 空行就是「只含 \n 的行」，用 list.count("\n") 就能数出来；
  • 统计单词：先用 " ".join(...) 把所有行拼成一大段，再用 .split() 按空白切分成单词列表，最后用 list.count(单词) 统计；
  • 处理 csv 时，先 line.strip() 去掉结尾换行，再 .split(",") 按逗号切成字段。

    print(contact)

第 28 讲 · 常见的内置数据类型都何时使用？ ​

本节目标 ​

记住每种类型「擅长什么」，从而在写代码时选对类型、少写代码。

知识要点 ​

常见数据类型一览：常量 None；逻辑值 True / False；空集 ''、()、[]、{}、set()、range(0)； 数字 int / float；序列 list / tuple / range；文本序列 str；集合 set；映射 dict。

哪些值代表「假」（bool() 会返回 False）：

  1. 常量 None
  2. 布尔值 False
  3. 数值 0、0.0
  4. 空的序列、映射（如 ""、[]、{}、set()）

比较规则因类型而异：

比较对象规则
数字按数值大小
字符串按首字母的 ASCII 编码大小
列表 / 元组从第一个元素开始逐项比较

选型口诀：

  • 要去重 → 用集合（自动去重最省事）；
  • 想避免被误修改 → 用不可变的元组；
  • 要键值对应 → 用字典；
  • 要有序、可增删 → 用列表；
  • 类型之间可以组合成更复杂的结构（列表套字典、字典套列表）。

第 29 讲 · 避坑指南：内置数据类型的常见错误 ​

本节目标 ​

认识内置数据类型最常出现的几类错误，学会读懂报错并知道怎么避免。

知识要点 ​

本章的错误大致分四类：

1. 访问错误——访问了不存在的元素：

  • 列表：IndexError: list index out of range（下标越界）
  • 字典：KeyError: 'xxx'（键不存在）
  • 解决办法：先判断元素是否存在（元素 in 对象）再操作，或用字典的 get()。

2. 不同类型之间操作报错——如 1 + 'a'，报 TypeError: unsupported operand type(s)。解决办法：转换成相同的类型。

3. 对只读类型写入报错——如对元组调用 append()，报 AttributeError: 'tuple' object has no attribute 'append'。写之前先确认类型（type(t)）。

4. 引用错误——用不可哈希对象（如列表）当字典的键，报 TypeError: unhashable type: 'list'。解决办法：用元组、字符串、数字当键。

三句话

  1. 数据类型是「装数据的容器」：列表有序可改、元组有序不可改、集合唯一无序、字典键值对应——选对容器，代码自然变短。
  2. 处理数据的通用套路是 非结构化（文本）→ 半结构化（键值对）→ 结构化（列表/字典），清洗、切分、转换三步走。
  3. 报错是最好的老师：先读最后一行看类型、再往上找出错行，不确定就 help() 或翻官方文档。
