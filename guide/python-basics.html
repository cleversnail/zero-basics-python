第 8 讲 · 修炼基本功：浅析输入输出 ​

本节目标 ​

看懂通用计算机模型里的「输入 → 计算/存储 → 输出」，并用 input()、print() 两个内置函数完成一次完整的输入输出。

知识要点 ​

1. 通用计算机模型

现代计算机基于冯·诺依曼结构，无论多复杂，它做的事永远绕不开四类任务：输入、输出、计算、存储、控制。写程序，就是把一件事拆成这几个部件。

举个例子——「算三个小数相乘」可以拆成：

  • 输入：读到三个小数
  • 存储：把它们临时记下来
  • 计算：做两次乘法
  • 输出：把结果打印出来

2. 输入的分类

  • 物理设备：键盘、鼠标、传感器、雷达、摄像头……
  • 逻辑概念：终端、文件、程序的可视化窗口……

3. input() 和 print() 的定位

它们是 Python 的内置函数（built-in function）——装好 Python 就能直接用，不需要 import，可以反复调用（调用就是让函数干活的动作，写法是函数名后面跟一对括号）。

📖 完整内置函数清单：https://docs.python.org/zh-cn/3.10/library/functions.html

4. 一个关键问题：输入的内容存到哪？

input() 读进来的东西，如果不「接住」，它转身就没了。要把它存下来，就得用变量（下一讲的主角）。这一讲先记住这个动作：

python
var1 = input("输入第一行内容\n")   # 把读到的内容存进 var1
1

= 是赋值语句：把右边得到的结果，交给左边的名字保存。

第 9 讲 · 变量：如何让计算机临时存储数据？ ​

本节目标 ​

搞清楚变量是什么、= 在干什么、变量为什么能反复改；掌握「一次赋多个变量」的写法。

知识要点 ​

1. 变量是什么

变量（variable）：程序运行过程中，用来临时保存数据的对象。你可以把它理解为「给内存里的数据贴的标签」——贴了什么名字，以后就用这个名字把数据取出来。

一行赋值 text = input() 拆开看：

部分名称含义
text变量名给这块数据贴的标签
=赋值操作符把右边的结果交给左边保存
input()值右边算出来的东西

⚠️ 注意：编程里的 = 不是「相等」，而是**「把右边装进左边」**。判断相等用的是 ==。

2. 变量指向一个值

在 Python 里，每个变量都指向一个值。除了用 input() 拿输入，也可以直接把值写给变量：

python
x = 1
y = "hello"
1
2

3. 变量理解为「贴标签」

x  ──►  123          # x = 123
y  ──►  "abc"        # y = "abc"
y  ──►  "zzz"        # 再执行 y = "zzz"，标签 y 就改指向新值了
1
2
3

同一个标签可以随时改指向——这就是「变量」名字里「变」的含义。

4. 几种不同的赋值写法

写法含义
a, b = 1, 2一行同时给两个变量赋不同的值（叫元组解包）
x = y = z = 3连续赋值，三个变量都指向 3

第 10 讲 · 字符串（上）：Python 是如何处理单词的？ ​

本节目标 ​

学会用三种引号定义字符串，会用 f-strings 把变量插进字符串，并掌握字符串的成员、连接、切片三类基本操作。

知识要点 ​

1. 什么是字符串

字符串（string，类型名 str）：一串文本字符，是 Python 最常用的数据类型之一。平时看到的单词、句子、文章，都是字符串。

2. 三种定义方式

写法特点
单引号 '...'里面可以再放双引号
双引号 "..."里面可以再放单引号
三重引号 '''...''' 或 """..."""可以跨多行

3. 字符串里插入变量：f-strings

在字符串前加一个 f，用 {变量名} 占位，运行时会被替换成变量的值：

python
x = 123
print(f"{x} 是变量 x 的值")
1
2

⚠️ f-strings 需要 Python 3.6 以上版本（本机 3.12.7，没问题）。

4. 三类基本操作

运算写法含义
成员运算x in s / x not in s子串在不在这里面，返回 True / False
连接运算s + t / s * n拼接两个字符串 / 把 s 重复 n 次
切片运算s[i] / s[i:j] / s[i:j:k]取第 i 项 / 取 i 到 j（不含 j）/ 取 i 到 j 步长 k

📌 下标从 0 开始：s[0] 是第一个字符；负数表示从后往前，s[-1] 是最后一个字符。

第 11 讲 · 字符串（下）：Python 是如何处理单词的？ ​

本节目标 ​

认识「方法」这个概念，掌握字符串最常用的六个方法：count、isalnum、isalpha、join、split、startswith。

知识要点 ​

1. 什么是「方法」

方法（method）：挂在某个对象身上的函数。写法是 对象.方法名(参数)，比如 "abc".count("a")——对字符串 "abc" 执行 count。

每种数据类型都内置了很多方法，专门用来处理这种类型的数据。

2. 本讲重点方法

方法作用例子 → 结果
str.count(sub)统计子串 sub 出现次数"abab".count("a") → 2
str.isalnum()是否全是字母或数字（且至少一个字符）"a1".isalnum() → True
str.isalpha()是否全是字母（且至少一个字符）"a1".isalpha() → False
str.join(iterable)用当前字符串做「胶水」把序列拼起来",".join("abc") → 'a,b,c'
str.split(sep)按分隔符拆成列表"a,b".split(",") → ['a', 'b']
str.startswith(prefix)是否以某前缀开头"xyz".startswith("y") → False

💡 join 和 split 是一对互逆操作：",".join(["a","b"]) 拼成 "a,b"，"a,b".split(",") 又拆回 ['a','b']。

📖 字符串全部方法：https://docs.python.org/zh-cn/3.10/library/stdtypes.html#string-methods

类型名称例子

第 13 讲 · 何时使用数字，何时使用字符串？ ​

本节目标 ​

看清「同一套运算符，作用在数字和字符串上结果完全不同」，理解「什么时候用数字、什么时候用字符串」，并认识跨类型运算会报 TypeError。

知识要点 ​

1. 为什么要区分数据类型

Python（还有 Java 等）都是强类型语言：类型不会因为运算中途改变，要改必须显式转。区分类型有三个好处：

  1. 有代码提示（IDE 知道这个变量能干哪些事）
  2. 执行效率高
  3. 安全、出错率低

2. 各管各的

  • 字符串：负责统计、语义（处理文字）
  • 数字：负责计算（处理数学）

3. 同一套运算符，两种行为

表达式结果为什么
100 + 200300数字做加法
"100" + "200""100200"字符串做拼接
456 > 1234False数字按大小比
"456" > "1234"True字符串按字典序比（逐位比字符）
len("456") > len("1234")False先取长度：3 和 4，再比大小，3 > 4 为假

💡 "456" 比 "1234" 大，是因为它先比第一个字符 '4' 和 '1'，'4' 更大就立刻定了胜负——字符串比较不看整体数值大小。

4. 跨类型运算会报错

python
>>> 123 + "456"
TypeError: unsupported operand type(s) for +: 'int' and 'str'
1
2

数字和字符串不能直接相加，必须先转成同一类型。

第 15 讲 · 小试牛刀：如何制作简单计算器？ ​

本节目标 ​

把「输入输出 + 变量 + 字符串 + 数字类型转换」合起来，做出一个能算四则运算的简易计算器，并认识 eval()。

知识要点 ​

1. 问题分解（需求分析）

做一个计算器，先想清楚：

  • 需求分析 1：实现简单的计算，用户自行输入算式
  • 需求分析 2：实现两个整数的四则运算，用户输入两个数后输入运算符，程序据此输出结果

程序设计包括：需求分析 → 代码编写 → 测试 → 维护和迭代。

2. 使用数字和字符串

  • 用户从键盘输入的数字，被 Python 当成字符串处理
  • 字符串不能直接做算术运算，得先类型转换
  • 转换后再计算

3. 解决未知问题：eval()

「怎样执行字符串里的表达式？」查官方文档和搜索引擎，答案是 eval() 函数——它能把一个「表达式字符串」当代码执行，算出结果。

python
eval("12+30")     # 得到 42
eval("8*4")       # 得到 32
1
2

配合 f-strings，把用户输入的两个数和运算符拼成表达式字符串：

python
result = eval(f"{num1}{op}{num2}")
1

⚠️ eval() 会执行字符串里的内容，方便但要小心：只用来处理你自己拼出来的、可信的表达式，不要直接 eval() 用户输入的任意字符串。

第 16 讲 · 变量命名规范：如何编写优雅的程序？ ​

本节目标 ​

知道什么样的变量名合法、哪些词是**关键字（保留字）**不能用，并养成好的命名习惯。

知识要点 ​

1. 为什么要学命名规范

  • 代码变长后，有意义的变量名能帮你快速看懂逻辑
  • 规范的命名能帮你区分变量代表的对象（函数、类……）
  • 规范的命名能帮你避免程序错误

2. 合法变量名的规则

  • 只能包含字母、数字、下划线，且不能以数字开头
  • 不能含空格
  • 不能使用关键字
  • Python 大小写敏感（name 和 Name 是两个变量）

来亲眼看看以数字开头会怎样：

3. 关键字（保留字）

关键字是语言保留的词，不能拿来当变量名。Python 3.12 的全部关键字共 35 个：

4. 好的命名习惯

  1. 简短
  2. 描述性强
  3. 全小写，多个单词用 _ 连接（如 user_name）
  4. 尽量不用中文，避开 l / 1 / L、0 / O / o 这类易混字符

速查表

主题关键点
输出print("你好")

字符串定义单引号 / 双引号 / 三重引号

数字类型int / float / complex
