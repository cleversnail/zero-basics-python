第 49 讲 · 函数的定义：如何优雅地反复引用同一段代码？ ​

本节目标 ​

学会用 def 把一段代码打包起来，并用圆括号随时把它「叫出来」跑一遍。

知识要点 ​

1. 函数的用途

把需要多次执行的代码片段「包装」起来，用到时就调用一次，从而提高代码的重复利用率——同一段逻辑写一次、用很多次。

2. 定义函数的语法

python
def 函数名称([函数参数]):
    函数体
    [return 返回值]
1
2
3
  • def 是 define（定义）的缩写，后面跟函数名和一对圆括号、一个冒号；
  • 函数体要缩进（通常是 4 个空格），缩进的部分才属于这个函数。

3. 调用函数

函数名后面加一对圆括号，就表示「调用」这个函数：foo()。 ⚠️ 注意：foo（不带括号）是函数对象本身，foo()（带括号）才执行它。

4. 匿名函数

匿名函数就是借用 lambda 表达式定义的一次性小函数，适合逻辑简单、只在一处用的场合：

python
add_1 = lambda x: x + 1     # 冒号左边是参数，右边是返回值
print(add_1(100))           # 101
1
2

它等价于一个正规函数 def add_1(x): return x + 1。

💡 一句话：def 负责「定义」，圆括号负责「调用」；lambda 是简写版的小函数。

代码实操 ​

完整代码见 code/49-define.py：

python
# -*- coding: utf-8 -*-
"""第 49 讲 · 函数的定义：如何优雅地反复引用同一段代码？"""


# 1. 定义函数：def + 函数名 + 圆括号 + 冒号，函数体要缩进
def foo():
    print("foo")
    print("is a function")


print("aaaaa")   # 这只是普通语句，不会执行 foo 里的内容
foo()            # 加圆括号才是「调用」，函数体这时才被完整跑一遍
foo()            # 再调用一次，同一段代码被复用

# 2. 函数对象 vs 函数调用
print(foo)       # 不加括号：得到的是「函数对象」本身
print(type(foo))

# 3. 匿名函数：用 lambda 表达式定义简单的、一次性的函数
add_1 = lambda x: x + 1
print(add_1(100))


# 上面那行 lambda，等价于下面这个正规函数
def add_1_def(x):
    return x + 1


print(add_1_def(100))

第 50 讲 · 函数的参数：怎样实现函数与外部数据通信？ ​

本节目标 ​

搞懂形参 / 实参的区别，学会用位置参数、关键字参数、默认值把数据送进函数。

知识要点 ​

1. 实参与形参

名称出现的位置例子
形参（形参变量）函数定义处def func(args): 里的 args
实参（实际参数）函数调用处func(variables) 里的 variables

一句话：形参是函数内部的「占位变量」，实参是你真正传进去的值。

2. 类型提示（Type Hint）

Python 3.5 起（PEP 484）支持类型提示：

python
def func(变量名: 类型) -> 返回类型:
    return 变量名
1
2

⚠️ 类型提示只对开发人员起提示作用，Python 不会据此做类型检查——传错类型照样跑，只是 IDE 会给你标红。

3. 位置参数

需要传多个参数时，最简单的方式是按顺序传递，靠「第几个」来对应参数，这叫位置参数：

python
def foo(argv1, argv2, argv3):
    pass

foo(one, two, three)   # one→argv1, two→argv2, three→argv3
1
2
3
4

4. 关键字参数与默认值

以内置函数 open() 为例，它的完整签名参数很多：

python
open(file, mode='r', buffering=-1, encoding=None,
     errors=None, newline=None, closefd=True, opener=None)
1
2

调用时可以指名道姓地只传你关心的：

python
open("/path/to/file", encoding="UTF-8")
1

这种「参数名=值」的写法叫关键字参数，它带来两个好处：可以换顺序、可以只传特定参数。

默认值：定义函数时直接给参数写个初值（如 mode='r'）。调用时若没传，就用默认值——参数越多，这个特性越省事。

💡 顺序提醒：位置参数在前、关键字参数在后；有默认值的参数应写在没有默认值的参数后面。

代码实操 ​

完整代码见 code/50-args.py：

python
# -*- coding: utf-8 -*-
"""第 50 讲 · 函数的参数：怎样实现函数与外部数据通信？"""


# 1. 形参与实参
def foo(number):          # 定义时的 number 是「形参」
    print(number)


n1, n2, n3 = 123, 456, 789
foo(n1)                   # 调用时传进去的 n1 是「实参」
foo(n2)
foo(n3)


# 2. 类型提示（Type Hint，PEP 484）：只给人看，Python 不做强制检查
def foo2(n1: int, n2: int) -> int:
    return n1 * n2


print(foo2(3, 4))


# 3. 位置参数 + 关键字参数 + 默认值
def foo3(argv1=100, argv2=200, argv3=300):
    print(argv1)
    print(argv2)
    print(argv3)


foo3("one", "two", "three")   # 三个都按位置传
foo3()                         # 一个都不传，全部用默认值
foo3(400, argv3=500)           # argv1 按位置，argv3 按关键字，argv2 用默认值

第 51 讲 · 函数的参数：当函数操作对象不固定时怎么处理？ ​

本节目标 ​

当参数个数不确定时，用 *args / **kwargs 接住它们；并学会写函数文档、用内省查看函数。

知识要点 ​

1. 不定长参数

  • 固定长度的参数让函数功能更明确；
  • 不定长度的参数让函数更灵活。

记号约定：

记号接收的东西表现为
*telphone多余的位置参数一个元组 tuple
**custom多余的关键字参数一个字典 dict

讲义里的「电话本」函数：

python
def address_book(name, *telphone, alias_name=None, **custom):
    print(f"name: {name}, tel: {telphone}, aname: {alias_name}, custom:{custom}")
1
2

不定长参数的变种：* 号后面不写变量名时，它只起到「分隔」作用——

python
def address_book(name, *, alias_name):
    pass
1
2

这里的 * 表示它后面的参数必须用关键字方式传，位置参数长度被固定成 2 个（name 和 alias_name）。

2. 函数文档（docstring）

函数体第一行的三引号字符串就是文档字符串，用来写「这个函数的用途、用法、注意事项」：

python
def foo():
    """ 这个函数的用途、用法、注意事项等 """
    pass
1
2
3

查看方式：foo.__doc__。

3. 函数内省

「内省」= 查看对象内部信息。把函数定义成函数对象后，它会自动带上一堆内置属性，用 dir(foo) 就能看到，例如 __doc__（文档）、__name__（函数名）、__defaults__（默认值）等。同样地，dir(列表)、dir(数字) 也能看到各种内置方法。

💡 知识串联：函数是「对象」，所以你也用过 dir() 查看字符串、列表的方法——底层靠的是同一套内省机制。

代码实操 ​

完整代码见 code/51-varargs.py：

python
# -*- coding: utf-8 -*-
"""第 51 讲 · 函数的参数：当函数操作对象不固定时怎么处理？"""


# 1. 不定长参数：* 收集位置参数，** 收集关键字参数
def address_book(name, *telphone, alias_name=None, **custom):
    print(f"name: {name}, tel: {telphone}, aname: {alias_name}, custom:{custom}")


address_book("wilson")
address_book("wilson", 1234, 4567, 5678)
address_book("wilson", 1234, 4567, 5678, home="Guangdong")
address_book("wilson", 1234, 4567, 5678, alias_name="w", aaa="bbb", home="Guangdong")


# 2. 函数文档：函数体第一行的字符串就是文档字符串（docstring）
def foo():
    """这个函数的用途、用法、注意事项都写在这里。"""
    print("test")


foo()
print(foo.__doc__)


# 3. 函数内省：用 dir() 查看函数对象自带的属性
print([d for d in dir(foo) if d in ("__call__", "__defaults__", "__doc__", "__kwdefaults__", "__name__")])
print(foo.__name__)

第 52 讲 · 函数的返回值：如何得到函数的执行结果？ ​

本节目标 ​

用 return 把函数的结果「交出来」，并认识「不写返回默认是 None」和「递归」。

知识要点 ​

1. return 语句

函数可以用参数接收「输入」，也可以把结果返回给调用者，让结果能继续参与后续运算：

python
var = func1()      # 把 func1 的结果接进 var
var2 = func1(var)  # 再拿 var 作为下次调用的输入
1
2

2. 返回值类型

return 的语法是 return [表达式]。如果函数里没有 return，或者只写 return（表达式为空），那么默认返回 None（「什么都没有」）。

return 后面可以跟多种东西：

python
return 变量
return 变量[, 变量, 变量]    # 返回多个值，其实是一个元组
return 字面值               # 如 return 3.14
return 函数调用
1
2
3
4

3. 返回函数调用与递归

函数可以直接返回另一个函数的调用结果：

python
def foo():
    return "abc"

def foo2():
    return foo()      # 返回的是 foo() 的执行结果
1
2
3
4
5

递归：函数调用自己。判断、循环、递归是三大基本算法。递归必须写好停止条件，否则会无限自我调用，最终抛出 RecursionError: maximum recursion depth exceeded（递归深度超限）。

求阶乘的递归写法（用中文描述就是）：

def 计算阶乘(数值):
    if 数值为 1 或者 0:
        返回 1              # 停止条件
    else:
        返回 数值 * 计算阶乘(数值 - 1)   # 自己调用自己
1
2
3
4
5

⚠️ 递归的停止条件是灵魂。没有它，函数会一直调用自己直到超出 Python 的最大递归深度。

代码实操 ​

完整代码见 code/52-return.py：

python
# -*- coding: utf-8 -*-
"""第 52 讲 · 函数的返回值：如何得到函数的执行结果？"""


# 1. return 把结果交给调用者，结果可以继续参与运算
def add(a, b):
    return a + b


result = add(3, 4)
print(result)
print(add(result, 10))


# 2. 没有 return（或 return 为空）时，默认返回 None
def no_return():
    print("我执行了，但没有返回值")


print(no_return())


# 3. 返回函数调用：return 后面可以跟「另一个函数的调用」
def foo():
    return "abc"


def foo2():
    return foo()


print(foo2())


# 4. 递归：函数自己调用自己，必须写好「停止条件」
def factorial(n):
    if n in (0, 1):
        return 1
    return n * factorial(n - 1)


print(factorial(5))

第 53 讲 · 小试牛刀：如何利用函数实现电商购物车功能？ ​

本节目标 ​

把「购物车」这个大需求分解成几个小功能，每个功能用一个函数实现，再把它们封装到一起。

知识要点 ​

1. 购物车的功能分析

购物车要方便客户：确认购买的商品名称、数量、金额、总额；调整商品数量；合并付款。简单拆分为：

  • 展示商品
  • 添加商品、删除商品
  • 调整商品数量
  • 费用总计

（本讲先忽略库存数量、商品类目。）

2. 数据结构

  • 商品表用列表：每行是 [商品编号, 名称, 类目, 单价]；
  • 购物车用字典：{商品编号: 数量}。

「展示商品」本质上就是遍历字典，逐个把商品名和数量打出来。

3. 费用统计

合计费用 = 单价 × 数量 + 单价 × 数量 + …

设计要点：只允许修改「数量」，每个商品的小计和总费用都在此基础上实时算出来——这样数量一改，总价自动跟着变，不会出现「价格和数量对不上」的不一致。

4. 数量修改的三条规则

  • 修改数量时，应避免为 0 或超过库存（暂不考虑库存）；
  • 购物车里数量减到 0 时，应把该商品移除；
  • 商品数量增减时，总价同步重算；
  • 用自定义函数比直接改字典更合适（逻辑集中、便于维护）。

💡 核心思想：先把完整功能拆成小功能，每个函数负责一件小事；再把相互作用的多个变量封装进函数统一处理。

# 商品表：每行是 [商品编号, 名称, 类目, 单价]
products = [
    [1000, "iphone", "phone", 12000],
    [1001, "ipad", "pad", 15000],
    [1002, "macbook", "laptop", 20000],
]

# 购物车：{商品编号: 数量}
cart = {1000: 5, 1001: 2}


def idtoname(product_id):
    """商品编号 -> 商品名称"""
    for product in products:
        if product[0] == product_id:
            return product[1]


def idtoprice(product_id):
    """商品编号 -> 单价"""
    for product in products:
        if product[0] == product_id:
            return product[3]


def show_cart():
    """展示购物车里的商品，并统计总费用"""
    total = 0
    for product_id in cart:
        print(f"购买商品 {idtoname(product_id)} 的数量为 {cart[product_id]}")
        total += idtoprice(product_id) * cart[product_id]
    print(f"总费用为: {total}")

    """加入购物车：已有就累加数量，没有就新增"""
    if product_id in cart:
        cart[product_id] += number
    else:
        cart[product_id] = number

    """购物车里某商品数量减 1，减到 0 就把它移除"""
    if product_id in cart:
        cart[product_id] -= 1
        if cart[product_id] == 0:
            cart.pop(product_id)


def clean_cart():
    """清空购物车"""
    cart.clear()

第 54 讲 · 避坑指南：列表作为参数传递出错了怎么办？ ​

本节目标 ​

看懂「列表作参数被就地修改」这个经典坑，并学会用副本规避它。

知识要点 ​

1. 列表类型的特殊性

  • 列表是可变数据类型（内容可以原地改动）；
  • 元组的元素可以是列表——所以「元组的某个元素」本身仍可能被改（元组只是「不让你换掉这一格」）；
  • 正因为可变，列表作为函数参数时，函数里对它的改动会影响到外面。

2. 列表作为函数参数

讲义里的例子：

python
list1 = [1, 2, 3]
def func(list1):
    list1.append(4)

func(list1)
print(list1)   # [1, 2, 3, 4]
func(list1)
print(list1)   # [1, 2, 3, 4, 4]

6
7
8

每调用一次，原列表就被追加一个 4——因为函数里 append 改的就是外面那个列表本身。

3. 为什么会这样

Python 传参时传的是「对象的引用」：函数拿到的 list1 和外面的 list1 指向同一个列表。所以函数内部一动，外面就看到变化。（数字、字符串等不可变类型则不会出现这种现象。）

4. 怎么规避

  • 原则：容易踩坑的可变数据，尽量不要直接当参数传进去改；
  • 若必须处理列表，就在函数里先 lst.copy() 复制一份，再对副本操作，或者干脆用 list(...) 新建列表。

⚠️ 一句话：把列表交给函数，函数里的改动会「漏」到外面——不确定时就先复制。

代码实操 ​

完整代码见 code/54-list-arg.py：

# -*- coding: utf-8 -*-
"""第 54 讲 · 避坑指南：列表作为参数传递出错了怎么办？

列表是「可变数据类型」。把它交给函数后，函数内部一改动，
调用方手里的那个列表也会跟着变 —— 这是最常见的坑之一。
"""

list1 = [1, 2, 3]


def func(lst):
    lst.append(4)   # 这一步会「就地修改」传进来的列表


print("调用前:", list1)
func(list1)
print("第 1 次调用后:", list1)   # 意外地多了个 4
func(list1)
print("第 2 次调用后:", list1)   # 又多了一个 4

def func_safe(lst):
    lst = lst.copy()   # 复制一份副本，动它不影响外面
    lst.append(4)
    return lst


print("原始列表:", list2)
print("函数返回值:", func_safe(list2))
print("原始列表没变:", list2)

1. 函数对象和函数调用

函数对象表示「函数本身」，可以赋值、可以当别的函数的参数或返回值；函数调用才是真的跑一遍。

2. 高阶函数

「高阶函数」指接收函数作为参数（或返回函数）的函数。Python 常说的三个高阶函数是 map、filter、reduce：

函数来源作用
map(函数, 可迭代对象)内置把函数作用到每个元素上，返回处理后的结果
filter(函数, 可迭代对象)内置过滤掉函数返回不为 True 的元素
reduce(函数, 可迭代对象)functools 导入对序列累积成一个值
  • map 的第一个参数可以是函数对象或 lambda；第二个参数是可迭代对象（列表、元组、range 等）。
  • filter 的规则等价于：function(item) 为真就留下。（function 为 None 时，直接按元素本身真假来留。）
  • reduce 需要 from functools import reduce。

3. 偏函数

偏函数：固定某个参数，生成一个新函数。

python
from functools import partial
new_func = partial(旧函数对象, 被固定的参数)
new_func(参数)

python

import time

知识要点 ​

一张函数地图

主题关键点
定义 / 调用def 名(参数): 定义；名() 调用；名 是函数对象
匿名函数lambda 参数: 表达式，适合简单、一次性的小函数

装饰器@time_it 给函数加料；@wraps 保住原函数的名字

三句话

  1. 函数把「反复要用的代码」打包起来，做到写一次、用很多次——这是结构化编程的第一步。
  2. 参数负责送数据进来（位置 / 关键字 / 默认值 / 不定长），return 负责把结果交出去。
  3. 把函数当对象用，就有了高阶函数与装饰器：函数可以赋值、当参数、当返回值，还能被「套一层」。

  3. 用 reduce 求 [2, 4, 6, 8] 的乘积。
  4. 把 code/54-list-arg.py 改成「传副本」的版本，确认原列表不再被改。

三句话
